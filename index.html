volcano-uploader

volcano-uploader 는 운영자 본인의 유튜브 채널에 직접 만든 영상을 올리기 위한 개인용 업로드 도구입니다. 운영자의 컴퓨터에서만 돌아가며, 다른 사람에게 서비스하지 않습니다.

이 도구는 YouTube API 서비스를 사용합니다. 사용하면 YouTube 서비스 약관에 동의하는 것이 됩니다.

개인정보처리방침

volcano-uploader is a personal upload tool that publishes the operator's own videos to the operator's own YouTube channels. It runs only on the operator's computer and is not offered to anyone else. It uses YouTube API Services; by using it you agree to the YouTube Terms of Service. See the Privacy Policy.
