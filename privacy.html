volcano-uploader 개인정보처리방침

시행일: 2026-10-29

1. 무엇을 하는 도구인가

volcano-uploader 는 운영자 본인의 유튜브 채널에 영상을 올리고, 그 채널의 영상 상태와 통계를 확인하는 개인용 도구입니다. YouTube API 서비스를 사용합니다.

2. 받는 정보

  • 구글 로그인 허락(OAuth)으로 받는 접근 열쇠 — 영상 올리기, 영상·채널 정보 수정, 채널 통계 읽기에만 씁니다.
  • 채널 이름·ID, 올린 영상의 ID·상태·조회수 같은 통계.

3. 저장과 공유

  • 위 정보는 운영자의 컴퓨터에만 저장됩니다. 외부 서버로 보내지 않습니다.
  • 누구에게도 팔거나 공유하지 않으며, 광고에 쓰지 않습니다.
  • 쿠키나 추적 도구를 쓰지 않습니다.

4. 허락 거두기와 삭제

언제든지 Google 계정의 서드파티 앱 접근 설정에서 이 도구의 접근을 끊을 수 있습니다. 끊으면 열쇠는 더 이상 쓸 수 없고, 운영자 컴퓨터에 저장된 열쇠와 정보는 지웁니다.

Privacy Policy (English)

volcano-uploader is a personal tool that uploads videos to, and reads status and statistics of, the operator's own YouTube channels using YouTube API Services.

Data accessed: OAuth access tokens (used only to upload videos, edit video/channel details and read channel analytics); channel name and ID; uploaded video IDs, status and statistics.

Storage and sharing: all data is stored only on the operator's own computer. It is never sent to any external server, sold, shared, or used for advertising. No cookies or tracking are used.

Revoking access: you can revoke access at any time via the Google security settings page; stored tokens and data are then deleted from the operator's computer.

See also the YouTube Terms of Service and the Google Privacy Policy.
